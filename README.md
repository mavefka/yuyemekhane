# yalova universitesi yemekhanesi ve duyurulari icin modern website

proje yalova universitesinin kendi yemekhane ve duyuru sayfalarindan verileri otomatik olarak ceker, gunceller ve modern bir arayuzle sunar. bulundugunuz gun dahil olmak uzere 7 gunun yemek menusunu, yemeklerin icindekilerini ve kalori hesabini goruntuleyebilir, menuyu yapay zekaya yorumlatabilir; ayni zamanda okuldaki guncel duyurulari, eklerini ve iceriklerini dogrudan site icinden okuyabilirsiniz.

varsayilan olarak amoled siyah temayla gelir, isterseniz ust bardan apple liquid glass (beyaz cam) temasina da gecis yapabilirsiniz.

sitenin live versiyonundaki scraper otomasyonu github actions uzerinde gunde 3 kez otomatik calisiyor fakat siz farkli sekillerde de tetikleyebilirsiniz.

vibe coding ile yapilmistir, daha hazirlik egitimime bile baslamadim. :D
tesekkurler, iyi kullanimlar.
